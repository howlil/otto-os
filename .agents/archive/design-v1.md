## Direction

Otto is a Windows shell surface borrowing the spatial confidence of macOS without pretending to own external application state. Its character is quiet, precise, and responsive. Its world is a layered desktop with one native source of truth for each window and a temporary captured visual layer for Genie motion. Its signature moment is the application being pulled into its exact Dock tile instead of merely shrinking in place.

Avoid large web-style slides, scale-from-zero windows, decorative bounce on window frames, and competing animation engines.

## Apple Human Interface Guidelines

Use the live [Apple Human Interface Guidelines](https://developer.apple.com/design/human-interface-guidelines/) as the primary external design reference for Otto's native UI. Before designing, changing, or reviewing a surface, open [Designing for macOS](https://developer.apple.com/design/human-interface-guidelines/designing-for-macos) and the current HIG pages for the affected pattern. Check [What's new](https://developer.apple.com/design/whats-new/) for relevant updates. Use Apple's Markdown view when the browser page requires JavaScript.

Apply the current guidance to Windows shell behavior, keyboard and pointer input, and Windows accessibility settings. Windows conventions and accessibility requirements take precedence where they conflict. In the task or PR, link the HIG sections that informed the change and explain any intentional departure. Update the affected rule in this file as part of the same change whenever current guidance changes a durable Otto UI decision.

- Keep hierarchy clear, controls familiar, and feedback immediate. Check the affected component alongside [Design principles](https://developer.apple.com/design/human-interface-guidelines/design-principles) and [Layout](https://developer.apple.com/design/human-interface-guidelines/layout).
- Reserve Liquid Glass for the functional layer above content. Otto's adaptive Clear treatment is a local choice. When reviewing it, assess legibility over representative backdrops, especially on text-heavy surfaces where Apple recommends Regular. Preserve the Windows opaque fallbacks. See [Materials](https://developer.apple.com/design/human-interface-guidelines/materials).
- For Control Center's dense popover, keep the outer Clear shell but put card text over the stronger shared menu fill. Small non-bold text on these cards must maintain 4.5:1 contrast across both adaptive ink variants.
- Check contrast, visible focus, keyboard access, UI Automation names, and the reduced-motion path. Use motion to explain state changes and keep the same actions available when motion is reduced. See [Accessibility](https://developer.apple.com/design/human-interface-guidelines/accessibility) and [Motion](https://developer.apple.com/design/human-interface-guidelines/motion).

## Guardrails

External HWND lifecycle state remains native Win32. Otto may mask minimize and restore with one temporary captured snapshot overlay; close remains native and does not route through the Dock.

The Dock stays visible over maximized or display-covering windows by default. Only its explicit auto-hide preference hides it, and moving the pointer to the bottom edge reveals it.

Motion values live in `otto-core::motion`; app and render layers do not duplicate timing policy.

Every transition is time-based, reversible from its current value, and safe to settle immediately when reduced motion is enabled. Genie locks one Dock target, uses shared strip boundaries on one bounded overlay, and restores through the exact inverse path.

## Patterns

The top-right cluster reads left to right as Tray Overflow, Wi-Fi, Volume, Battery, Search, Control Center, Notifications, and Date/Time. Left-side application menu slots use uniform `10 pt` horizontal padding (`MENU_SLOT_HORIZONTAL_PAD_POINTS = 10`) around measured labels, and popup menus use concentric `13 pt` outer shells with `8 pt` hover pills at `5 pt` padding (`13 - 5 = 8`). Each action owns one hit rectangle and one hover, pressed, open, or focus treatment; no control uses a permanent pill. Date/time opens only the calendar, while the bell opens a compact macOS-style Notification Center (`otto-core::menu::notification_center`, `328 pt` shell at `20 pt` radius, `8 pt` pad, concentric `12 pt`-squircle cards with adaptive `50 / 64 / 76 pt` heights for body-less, single-line, and two-line alerts) with a `13 pt` `"Notifications"` + borderless-at-rest `"Clear All"` hover-pill header, collapsed multi-item app stacks showing an inline `+N` eyebrow pill beside the app name and up to two `4 pt` recessed card edges clipped cleanly below the front card (zero bleed through translucent glass) that expand in place with `"Show less"` and `"Clear"` pills, `32 pt` real app icons (WinRT `DisplayInfo::GetLogo` plus STA Shell/catalog premultiplied BGRA fallback without artificial icon box frames, falling back to luminance-matched monograms via `badge_ink_is_dark`), tabular timestamps swapping on hover to a `16 pt` circular `×` inside a `24 pt` hit target, card-body click to open the source app and remove the toast, and empty/permission state cards. The calendar is one pure layout in `otto-core::calendar` shared by render and input: a `252 pt` popup, `40 pt` header (15 pt semibold month name, regular secondary year, and three `26 pt` circular controls: chevron, today dot, chevron, with a neutral hover pill), a `22 pt` single-letter weekday row (11 pt semibold, secondary), and a fixed `6 x 30 pt` grid so the popup never changes height between months (13 pt numerals, neighbouring-month days at 55% opacity). Today is a system-red filled disc with a white semibold numeral (the accent colour in high contrast). Apple publishes no written spec for this visual, so these values follow the Apple Calendar look and are tuned by eye. Only one Otto popup or Control Center surface remains open, and any action hidden by width pressure stays reachable through explicit overflow.

Spotlight is a focused, movable and resizable app-search window (`28 pt` outer squircle shell, `16 pt` inset, concentric `12 pt` search field on the `4 pt` grid). Top-bar Search and `Ctrl+Alt+Space` open Search; Dock Apps opens the full catalog. Search ranks local app names while typing, keeps keyboard selection visible, launches with Return, closes with Escape, and switches list/grid with Tab. Its shell morphs from the trigger into the centered work-area window; reduced motion goes directly to the final state. The search field names its scope as local apps.

Wi-Fi, Volume, and Battery have independent actions; unused status space has no action, and only Volume accepts wheel adjustment. The Control Center opens from the activated status icon and uses a top-right-anchored scale morph on open and page changes, driven by `MotionMetrics`; reduced motion settles immediately.

Privacy uses one menu-bar dot at a time: camera activity takes precedence and is green; then active microphone use is orange; then location use shows a blue arrow. Clicking the dot opens privacy details; microphone mute remains a separate control.

Notch media controls (Music tab) hit at 24 px minimum; the visual track may be smaller and is centered in its hit rect. Controls in the expanded notch keep at least 4 px between hit rects and never cross the notch curve. Dimmed or unsupported controls must name the reason, and "engaged" means hovered or keyboard-focused, so the reason reaches keyboard users too.

Expanded Music subtitle priority: an engaged unsupported control's reason (up to two lines, replacing the equalizer), then the active lyric in the cover accent, then the artist ("Paused · artist" while paused). The lyrics drawer does not suppress the header line.

Icons are drawn vector glyphs. A text character never stands in for an icon.

Lyrics drawer follows the Apple Music reading model in a bordered card: a 12 pt rounded squircle card (concentric with the 28 pt outer shell at 16 pt padding; 5 % fill, 10 % frame, 102 pt tall at 14 pt vertical-balanced inset and 16 pt top/bottom edge fade) holds the rows, the active line sits on the vertical centre without a highlight background pill, text is left-aligned with a 14 pt inset, and only three rows are visible (previous, active, next). The active line is 16 pt bold; neighbours use a continuous smoothstep opacity (38 % at one row away, 0 % by two rows) and normalized concentric soft blur (up to 2.2 px at 96 dpi, blurring smoothly once focus distance exceeds 0.18 while capping incoming pre-active rows cleanly so rows transition without a brightness pop or card-edge crowding). A line that fits stays on one line, a line up to 14% too wide shrinks to fit, and only a longer line wraps (two lines at most). Scroll keeps the active row on the centre using each row's measured height and anticipates each timestamp by 120 ms with a 120 ms settle glide (clamped monotonically for fast lines), while controller wakeups target exact lyric timestamps and a 120 ms sync drift ceiling. The active line fills left to right with a 10 pt feathered edge across its gap to the next line (capped at 6 s), continuing line by line when it wraps. Scroll and fill derive from the playback position, so seeking needs no extra state. Reduced motion shows the active line fully bright with no glide or fill. Reference recreations of Apple Music (am-lyrics, SwiftUI clones) anchor the active line near the top; this card keeps the active line centered without a pill box so gradient blur and scale hold hierarchy cleanly.

Notch morphs: switching Focus and Music slides the two content groups 24 pt and crossfades them; opening the lyrics drawer interpolates the notch height, the drawer, and the seek bar (the hero and transport stay put); opening the panel rises its content 8 pt as the shape grows. Island expansion, compact swaps, and tactile capsule press compression (`press_progress` up to 3% scale around the floating center or flush top edge) are driven by 2nd-order spring physics in `MotionMetrics`. The primary and secondary pills stay two separate shapes with an `8 pt` gap and no bridge between them. Reduced motion jumps every morph to its target.

Pomodoro: solid semantic accents tint progress and controls: Focus orange, Short Break green, Long Break blue, and neutral QuickTimer/Stopwatch; the panel time and labels stay neutral. Pausing dims the accent, with no decorative glow. The last minute of a focus session turns the time and ring coral and adds a thin coral rim. Compact Focus: Classic Notch 200 x 32 pt; Dynamic Island 184 x 36 pt active from 120 x 32 pt idle, with optional width for privacy dots and symmetrical `12 pt` time/trailing insets. Focus shows a clean progress ring on the left, four solid cycle steps centered, and a 13 px neutral OpenType tabular-figure (`tnum`) time on the right. Dynamic Island Music keeps its 292 pt base at 36 pt high, widening for longer title or lyric text to 520 pt of content, plus the privacy-dot reserve when visible. The 2.5 s event peeks replace the steps and fade in and out. QuickTimer and Stopwatch retain the ring and time without Pomodoro steps. When both Focus and Music are active in compact mode, the active primary module renders its full single-activity layout in the Main Notch (`layout.notch`) while the secondary module detaches into an Obsidian Black circle (`layout.notch_secondary`: `36 x 36 pt` matching active Dynamic Island height when floating, or `28 x 28 pt` inside the `32 pt` flush top bar) 8 pt to the right of the Main Notch; clicking the secondary circle swaps the two modules (`compact_swap_blend`) and syncs the expanded panel tab to the Main Notch module, while right-clicking either slot dismisses that slot independently. Panel (380 x 144 pt, `28 pt` expanded Dynamic Island corner radius, 16 pt inset, three rows): header (`10 pt` tab top so `8 pt` strip and `10..34 pt` pills clear the `28 pt` curve and stay `>= 4 pt` above `38 pt` hero/body; Focus, Break or Rest tab beside Music, and the session label), hero (48 pt phase icon, 30 px tabular time, derived subtitle such as "Deep focus · ends 12:48", then reset, a 40 pt primary, and skip), and progress (four session segments while focusing, one continuous bar on breaks, with the start time and the next break). Idle focus shows the 15, 25, 45 and 60 minute presets in place of progress; scrolling stays as fine-tune. Completion shows one card in the next phase's colours with +5 min and Start break or Start focus. Phase glyphs (tomato, cup, outline moon, check, clock) use original vectors on one shared stroke scale. Reduced motion keeps the urgent rim static and shows peeks without fades. Copy and the surface for each state are resolved in `otto-core::pomodoro_view`, rects in `otto-core::layout`; render only draws them.

Screen Time (`Time`, dedicated expanded Notch tab beside `Focus`, following Apple HIG [Charting data](https://developer.apple.com/design/human-interface-guidelines/charting-data), [Widgets](https://developer.apple.com/design/human-interface-guidelines/widgets), and [Layout](https://developer.apple.com/design/human-interface-guidelines/layout)): the expanded Notch widens to `416 pt` (`Metrics::notch_expanded_width = 416`, `content = 384 pt`) so all 6 adaptive tabs (`Focus`, `Time`, `Shelf`, `Clip`, `Tasks`, `Music`) fit without colliding with any right-side header controls across all DPIs while keeping the `Focus` (Pomodoro) tab dedicated to timer controls. Selecting `Time` (`NotchTabStats`, drawn with a vector 3-bar chart glyph) smoothly morphs the expanded Obsidian Black Notch height from `144 pt` to `196 pt` (`Metrics::notch_stats_height = 196`, reusing `notch_lyrics_morph_rate`; settles immediately in reduced motion). The header right side holds the `Today | 7 Days` segmented switch (`48 + 4 + 48 pt`) and trailing `Details ›` pill (`60 pt`, `FocusStatsOpenSettings`, collapsing the Notch and opening `OttoSettings` straight to `Focus → Activity`). Below sits one concentric `12 pt` rounded squircle Bento card (`384 x 138 pt`, `5.5 %` fill, `10 %` hairline rim, high-contrast lifted borders). `Today` uses an asymmetric split: left hero (`Screen Time` + optional quiet `#30D158` blocked-distractions count when `> 0`, `22 pt` semibold `tnum` total, `38 pt` `#FF9230` Focus share ring with centered `%`, and Focus time), vertical `1 px` hairline divider, and right `Most Used` Top 3 apps with real `20 x 20 pt` (`5 pt`-radius squircle) application icons extracted lazily via `extract_app_icon_bitmap` (with deterministic tinted squircle monogram fallback), top-browser domain hint (`Chrome · domain` without double-counting), right-aligned `tnum` durations, and `#0A84FF` luminance-stepped usage bars (with a calm empty state when zero usage is recorded). `7 Days` pairs a dynamic `tnum` readout (`Avg X/day · Y% focus`, updating on pointer hover, keyboard focus, or click-to-pin day selection) and a 2-item `Screen`/`Focus` legend above 7 interactive stacked columns (`#0A84FF` Screen Time + `#FF9230` Focus + `#30D158` dashed `avg` reference line + weekday labels + Today dot). View data is resolved in `otto-core::notch::focus_stats_view` from `FocusActivityState`, geometry in `otto-core::layout`; `otto-render::notch::focus_stats` only draws them.

Music: the cover's dominant colour (muted toward neutral) tints the play button, seek fill, lyric highlight, and equalizer; text stays neutral. Panel (380 x 144 pt, same 16 pt grid as Pomodoro): header (Focus and Music tabs, the source label such as Spotify or Browser, and a 24 pt lyrics toggle drawn as a vector quote mark), hero (48 pt rounded cover without an external halo, 15 px title, 11 px artist, a small equalizer in the same muted tint, then previous, a 40 pt primary, and next), and progress (a 4 px seek bar with elapsed and remaining time; hover adds a 10 px thumb and lifts the fill 14 %). Paused dims the cover to 55 % and turns the equalizer into four neutral dots, and reads "Paused · artist". A source without a length shows LIVE and a soft segment drifting along the bar instead of a fill. Opening lyrics grows the panel to 254 pt with the 102 pt drawer between hero and seek bar (balancing top and bottom padding around three rows with the 14 pt side inset). Compact (292 pt base; 36 pt high when active in Dynamic Island): symmetrical edge anchors pair a 20 pt left cover with a quiet 16 pt right equalizer slot (expanding to 34 pt only for the red `LIVE` badge via `media_live`), keeping the centered title, synced lyric line, or centered peek (`label + title`) equidistant between cover and wave. A pause keeps the compact island for 8 s with a dimmed cover and a flat equalizer, then it collapses. 2.5 s peeks (Now playing, Paused, Playing, Skipped, each as a muted label before the title) replace the title when something happens and are not shown while the Pomodoro owns the compact island. Reduced motion shows peeks without fades and parks the live segment in the middle. Copy, the subtitle choice, and the dominant colour are resolved in `otto-core::media_view` and `otto-core::cover_color`, rects in `otto-core::layout`; render only draws them.

Privacy indicators: active microphone (orange) or camera (green) capture places 6 pt indicator dots in `layout.privacy_dots` beside the bar notch (clicking opens and pins the notch panel, switching from Focus or absent Media to Pocket so the mic control is immediately visible). While microphone/camera is active or the mic is muted, Pocket (`40 pt` compact), Clip (`40 pt` compact), and Music (`88 pt` labeled pill with app name) surface a header `PrivacyMicMute` toggle pill.

Notch notifications (OS event): a Windows toast arriving while the notch is idle becomes one island event, resolved in `otto-core::notch_notification`, laid out solely in `otto-core::layout::notification`, and drawn by `otto-render` without OS queries. Priority is Alert, then Ringing call, then open panel, then Message (`Peek` or `Banner`), then HUD, then compact activity; a message never closes a panel the user opened. Calls and messages follow a clear two-stage choreography:
- Message, Peek (`1.0 s`, compact `OttoNotchBar` pill): the notch swells with `island_compact_response`/`damping` to compact width (`292 x 36 pt` Dynamic Island, `292 x 32 pt` Classic Notch, plus privacy-dot reserve when active) without opening `OttoNotchPanel`. Reuses `CompactNotchGeometry`: leading `20 pt` `6 pt`-squircle app icon (`DisplayInfo::GetLogo` cached via WIC with luminance-matched monogram fallback), center sender/headline in `12 pt` semibold (`FOREGROUND 96%`), trailing quiet tabular count pill (`11 pt` `tnum`) only when coalesced (`count > 1`) or queued (`pending > 0`). Hover promotes immediately to Banner; left-click opens the source app; right-click or swipe up collapses without removing from Notification Center.
- Message, Banner (`380 x 92 pt` Obsidian card in `OttoNotchPanel`, expanded radius `28 pt` island / `22 pt` classic, `8 pt` enter rise): strict `4 pt` grid with zero control overlap. Leading `44 x 44 pt` G2 squircle (`x: 16..60, y: 24..68`, concentric `12 pt` radius, `1 px` `FOREGROUND 12%` inner rim) displays the real app icon or luminance-matched monogram (`18 pt` semibold, `>= 4.5:1`). Text column (`x: 72..364`): Row 1 (`y: 12..28`) shows app name (+ quiet `· N` when coalesced) in `11 pt` medium (`FOREGROUND 60%`, `x: 72..328`) and right-aligned relative age (`11 pt` `tnum`, `FOREGROUND 52%`) that swaps cleanly on card hover or close focus to a `24 x 24 pt` circular close control (`x: 340..364, y: 8..32`, `20 pt` visual disc) without intersecting Row 2; Row 2 (`y: 32..50`) shows title in `13 pt` semibold (`FOREGROUND 96%`); Row 3 (`y: 50..82`) shows body in `12 pt` regular (`FOREGROUND 78%`, max 2 wrapped lines with ellipsis). Empty-body messages center Row 1 + Row 2 vertically against the badge. Hovering the card adds a quiet `FOREGROUND 4%` surface lift and holds dismissal with a `1.5 s` leave grace; hold is `4.5 s` + `40 ms/char` past 60 chars (cap `9 s`). Left-click opens the source app and removes the toast; `×` removes the toast without activating the app; swipe up, click outside, right-click, or Escape collapses the banner while keeping the toast in Notification Center.
- Queue & bursts: same-app bursts within `3 s` coalesce into one card with a count (`6 pt` content cross-dissolve); other apps queue FIFO up to 4 (`NOTIFICATION_QUEUE_LIMIT`), signalled by a `4 pt` recessed obsidian second-card edge (`356 pt` wide, `24 pt` bottom curve, `FOREGROUND 10%` rim) below the island and a quiet `+N` suffix on the header row.
- Call, Ringing (`380 x 96 pt` card, no auto-dismiss timer, `60 s` ring timeout to Missed Call banner): leading `48 x 48 pt` circular avatar (`x: 16..64, y: 24..72`) with a `1.4 s` ease-out pulsing `#30D158` ring (static in reduced motion); centered two-row text column (`x: 76..252, y: 28..68`, midpoint `48 pt`) with `{app_name} · Incoming Call` / `Incoming Video Call` (with inline `12 pt` vector camera glyph) in `11 pt` medium (`FOREGROUND 62%`) above caller name in `15 pt` semibold (`FOREGROUND 98%`); trailing `44 x 44 pt` circles `12 pt` apart (`decline` `x: 264..308` in `#FF453A` with downward SF-style filled handset, `accept` `x: 320..364` in WCAG-AA `#24A148` with upward handset or video camera glyph, `+10%` hover lift, `0.94` press scale). Accept honestly opens the call window; Decline dismisses the alert. Return opens and Escape dismisses. A call preempts any message (restoring it afterwards); vanishing source toasts clear the ring immediately.
- Call, in progress (compact pill): while a call app holds mic or camera, compact Main Notch shows a properly scaled filled `#30D158` handset or camera (or `#FF453A` slashed mic while muted), a center-weighted 5-bar organic voice waveform (5 muted dots when muted; calm static chord in reduced motion), and `13 pt` `tnum` elapsed time, pushing Focus or Media to `NotchSecondary`. Clicking expands the panel with `PrivacyMicMute` visible.
- Rules & Focus/DND: Focus sessions and Windows Do Not Disturb suppress message peeks/banners and instead show a quiet `5 pt` unread dot on the Top Bar Notifications bell (`notification_slot`); calls still ring unless blocked by Focus blocklist. Previews off shows app name + `"New notification"` on Peek and Banner, never hiding a caller. Reduced motion skips springs, rises, and ringing/waveform loops while keeping durations and `120 ms` crossfade. Keyboard focus draws a concentric inset squircle focus ring on `NotificationCard` (never clipping `panel_window`) and circular rings on `NotificationClose`, `NotificationAccept`, and `NotificationDecline`. The island remains excluded from captures like every glass surface.

Pocket (File Drop Shelf, expanded panel tab): holds up to 12 items (`MAX_SHELF_ITEMS`) across two 3x2 card pages (`SHELF_PAGE_SIZE = 6`) inside a 90 pt high card body (`SHELF_BODY_HEIGHT_POINTS = 90`). Header holds optional page indicator (`1/2`), a 40 pt vector-plus `Add` pill, and (when populated) a 38 pt red-tinted `Clear` pill. Empty state draws a dashed rounded dropzone (`Drop files, links, or text here`, switching to `Release to keep in Pocket` and blue highlight on OLE drag-hover) and opens the file picker on click; populated state renders 3x2 cards with square thumbnail/glyph tiles (up to 128 px Shell thumbnails cached per item or drawn vector glyphs for 10 `ShelfKindTag` kinds), label, and 18 pt Copy and Remove vector mini-buttons. Left-click opens files/URLs or copies text; drag past `SM_CXDRAG`/`SM_CYDRAG` starts an outbound OLE drag (`CF_HDROP` / `CF_UNICODETEXT` / URL); right-click reveals files in Explorer or copies links/text. Drag-entering the notch or open panel switches to Pocket and uses a 220 ms `DragLeave` grace across the dual-HWND notch boundary; pointer-leave collapse stays suppressed while drag-hover, drag-opened inspection, modal file picking, or outbound drag holds.

Clipboard (Clip, expanded panel tab beside Pocket): holds up to 12 ephemeral RAM-only recent copies (`MAX_CLIPBOARD_ITEMS = 12`) across 4-row pages (`CLIPBOARD_PAGE_SIZE = 4`) inside a 90 pt high body. Header holds an optional page indicator (`1/3`), a `Live`/`Paused` capture pill, a `Clear` pill (when populated), and the Privacy mic control when active; each row displays a vector kind glyph (`Text`, `Link`, or `Files`), a sanitized single-line preview, compact byte/item metadata, transient `Copied` visual confirmation on click, and a trailing remove `×` button. Sensitive and opt-out clipboard formats are skipped.

Transient HUD (OS events) uses one template for every event: glyph, neutral label, meter, value, in fixed columns of the 356 pt pill. Labels stay neutral; accent colour belongs only to the glyph, meter, and value. Green means charging or Caps Lock on, amber means low battery, and muted means off or muted. Muted volume reads as the word "Muted" with an empty meter. Caps Lock shows a state pill and never a meter. The meter is a continuous 4 pt bar, not segments. Content fades in after the shape has mostly grown (`hud_content_alpha`), and each new event restarts the hold (`MotionMetrics::hud_hold_ms`). Presentation and geometry are resolved in `otto-core::hud`; render only draws them.

Liquid glass (bar, Dock, Control Center, Spotlight, and Popup Menu) supports user-selectable appearance preferences in `OttoSettings` (`AppearanceStyle::{LiquidGlass, Frosted, Tinted, Solid}`, `ThemeMode::{Auto, Light, Dark}`, and `AccentColor::{System, Blue, Purple, Rose, Amber, Emerald, Graphite}`, defaulting to `LiquidGlass + Dark + Blue` and persisted under additive `appearance_style`, `appearance_theme`, and `appearance_accent` keys; legacy `theme_mode` and `liquid_glass` config keys remain readable and ignored for compatibility). Surfaces follow MacBook Pro PROLED XDR & Apple HIG geometry: strict `4 pt` grid alignment, concentric radii (`R_inner = R_outer - d`), G2-continuous superellipse (squircle) corners with a `1.528665 R` shoulder (blending smoothly from circular capsule caps when `lx == R` or `ly == R`), OpenType tabular figures (`tnum`) on live clocks, HUD percentages, timers, seekbar timestamps, calendar days, and Settings KPI/chart readouts, and a directional PROLED specular rim (`0.18 -> 0.06 -> 0.11` vertical alpha gradient) on floating notch surfaces. Center Notch / Dynamic Island remains Obsidian Black (`#000000`) outside High Contrast, while Focus Shield uses the resolved `Appearance` palette and concentric squircle framing. Each active glass surface samples its backdrop, applies a `12 pt` soft blur (flat Regular-style surface: blur and tint carry the material, and the edge stays a thin hairline instead of a raised bevel), and uses average luminance with `0.44`/`0.56` hysteresis to select white or graphite ink without flicker. The `LiquidGlass` body keeps low tint (`0.05` Dark-ink / `0.07` graphite-ink), chroma-preserving grading (Dark luma ceiling `0.66`, which keeps white ink at WCAG AA over the brightest backdrop; `0.72` also passes but washes the surface out; saturation `1.30`), a bright legibility floor for graphite ink (`0.52`), a fixed-direction `1.2 px` specular hairline (`rim_lit 0.55`, `rim_bounce 0.20`; the light never follows the pointer, so hovering a card does not move highlights along its edge), a faint inner glow (`0.05`), and a thin `10 px` convex bezel (`min(lens_band, 44%` of the short half-axis, `6 px` refraction shift, `0.5 px` dispersion, `55%` sharp backdrop weight at the meniscus) whose Snell-style refraction and RGB dispersion stay concentrated near the meniscus while the body remains softly frosted; `Frosted` applies high-tint diffused matte without lens distortion and `Tinted` adds calibrated accent hue. Top bar glass bleeds 22 pt past top/left/right edges so only its bottom edge refracts. Fallback priority is strictly Windows High Contrast > `AppearanceStyle::Solid` (opaque, zero backdrop capture) > Windows Reduce Transparency / unavailable blur / Battery Saver (opaque fallback) > selected glass style.

Control Center uses Clear Layered Glass in a `376 pt` Main Apple Bento shell on a strict `4 px` grid (`26 pt` shell radius, `14 pt` card radius, `12 pt` outer pad so `26 - 12 = 14`, `12 pt` uniform card inner pad, `8 pt` Bento gutter, `10 pt` concentric `4 pt`-inset row/header hover pills): top-left `Connectivity` (`144 pt`) holds Wi-Fi & Bluetooth (`32 pt` circular switches, `10 pt` icon-to-text gap, inset hairline separator, chevron openers); top-right stacks matching `68 pt` horizontal `Focus` and `Battery` tiles using the same `32 pt` circular icon and centered two-line typography (`13 pt` semibold primary titles across every Main card, `11 pt` medium secondary subtitles/tabular readouts), with Focus keeping a vertically centered `24 pt` corner settings action. There is no Appearance card, glass toggle, or theme strip. Middle `68 pt` rows render identically aligned `Display` and `Sound` cards with `328 x 26 pt` full-width capsule sliders whose leading `26 x 26 pt` semicircle cap embeds the Sun glyph on Display and the clickable `SoundMuteToggle` speaker glyph on Sound. The bottom `72 pt` `Now Playing` row uses symmetrical `12 pt` framing around the `48 pt` cover art and a `32 pt` circular Play/Pause primary button flanked by `26 pt` Prev/Next glyphs. Subpanels reuse the same `12 pt` inner padding, `68 pt` slider cards, `14 pt` concentric footer buttons, reserved `8 pt` right scrollbar gutter, inset `1 px` dividers, tactile `SetCapture` press/cancel feedback, and keyboard/UIA parity.

Otto Settings is a normal resizable Windows window that follows the macOS System Settings layout ([Sidebars](https://developer.apple.com/design/human-interface-guidelines/sidebars), [Toolbars](https://developer.apple.com/design/human-interface-guidelines/toolbars), [Lists and tables](https://developer.apple.com/design/human-interface-guidelines/lists-and-tables), [Toggles](https://developer.apple.com/design/human-interface-guidelines/toggles)): a `240 pt` sidebar (collapsing to a `60 pt` icon rail under `760 pt`) of `34 pt` rows, each with a `24 pt` colored squircle glyph tile and an accent-filled selection; a `52 pt` toolbar carrying the page title with a hairline only once content scrolls under it; and a content column capped at `680 pt` made of inset grouped cards (`10 pt` radius, `16 pt` row padding, inset hairlines, `52 pt` rows with a subtitle, `44 pt` without) under `12 pt` section headers with `11 pt` footers that explain consequences. Controls are `38 x 22 pt` green switches, popup-style choices with up/down chevrons, disclosure rows with a chevron, status as a colored dot plus label, and keycaps for shortcuts. Overview and About open with a hero (`76 pt` Otto icon, title, subtitle); no page is an empty canvas. Glyph tiles are drawn vectors on one stroke scale, and the window uses native Windows 11 Mica (`BackdropMaterial::Mica` / `DWMSBT_MAINWINDOW = 2`) with the frame extended into the client area, a subtle sidebar tonal shift, and uniform neutral cards with hairline borders following the resolved Light/Dark theme and Accent color; with `AppearanceStyle::Solid`, Windows transparency off, high contrast, or Battery Saver it falls back to solid surfaces and DWM caption colors instead of the Windows accent title bar. Clear Liquid Glass remains reserved for transient Notch, Bar, Dock, Control Center, Spotlight, and Popup surfaces. Layout and rows are resolved in `otto-core::settings_window` and `otto-core::settings_content`; `otto-render::settings` only draws them. Otto's captured-backdrop refraction is not used here (it needs a layered window); an in-window search field and in-row keyboard focus are not built yet.

## State

Platform observation owns the truth about external windows. App state owns local animation progress. Core owns interpolation and resolved geometry.

Closing feedback must recover if the target window remains visible, for example because the application opened an unsaved-changes dialog.

## Accessibility

Read Windows client-area animation and UI-effects preferences. Reduced motion removes bounce and interpolation while preserving the same actions and final states.

Notch controls join the bar keyboard order only while the expanded panel is open: the Focus (`Pomodoro`), `Shelf` (`Pocket`), and `Clipboard` (`Clip`) tabs when their respective module is enabled, the `Media` tab and media controls only when the media module is enabled and media is present, and `PrivacyMicMute` whenever its pill is shown. Collapsed `Notch`, active `NotchSecondary`, and `PrivacyIndicator` also participate in bar traversal; activating collapsed `Notch` opens the panel and moves focus to the active tab strip. On the Focus tab the Focus sub-mode selectors, presets (idle focus/timer), reset, play or pause, and skip are reachable; while the session-complete card shows, only +5 min and the next-phase button are. On the Screen Time (`Time`) tab, `Today`, `7 Days`, `Details` (`FocusStatsOpenSettings`), and the 7 weekly day columns (`FocusStatsDay(0..6)`, whose keyboard focus also updates the readout) are reachable. On the Pocket tab pager (when multi-page), Add, Clear (when populated), visible card tiles, and their per-card copy and remove actions are reachable; on the Clipboard tab pager (when multi-page), Pause/Live, Clear (when populated), visible rows, and row remove buttons are reachable. Tabs, lyrics toggle, previous, play/pause, next, and the seekbar are reachable on the Media tab; Left and Right seek by 5 s while the seekbar is focused. Each focused control draws a focus ring, activates through the same path as a click, and is exposed through UI Automation (`WM_GETOBJECT` / `IInvokeProvider`) across the Bar, Notch panel, Dock, and Control Center.
